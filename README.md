# 🌌 SpaceVoyage

SpaceVoyage is a modern space-themed website designed to explore the beauty of the universe through interactive sections, stunning visuals, and smooth animations. The project delivers an immersive experience about planets, galaxies, missions, and space exploration.

---

## 🚀 Features

- 🌍 Modern responsive design
- ✨ Smooth hover animations and transitions
- 🪐 Planets exploration section
- 📸 Space gallery with breathtaking visuals
- 🚀 Missions section
- 📬 Contact form
- 🌌 Futuristic UI inspired by space aesthetics

---

## 🛠️ Built With

- HTML5
- CSS3
- Google Fonts
- Flexbox
- Responsive Design
